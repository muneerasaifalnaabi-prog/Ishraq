# Ishraq (إشراق) ✨

**Ishraq** is a premium, elegant productivity and lifestyle application specifically designed for women. It combines habit tracking, task management, and wellness tools with a stunning, customizable user interface that supports both Arabic (RTL) and English (LTR).

## 🌟 Key Features

### 1. Task Management (إدارة المهام)
- **To-Do List**: Add daily and weekly tasks effortlessly.
- **Prioritization**: Categorize tasks as High (مهم) or Normal (عادي).
- **Deadlines**: Keep track of upcoming deadlines.
- **Recurring Tasks**: Set up daily routines.

### 2. Habit Tracker (تتبع العادات)
- **Wellness Habits**: Track water intake, exercise, reading, and prayer/meditation.
- **Progression**: Visual progress bars and streak tracking (🔥) to keep you motivated.
- **Consistency**: Monthly calendar view to visualize your commitment.

### 3. Daily Planner (الجدول اليومي)
- **Time Blocking**: Segment your day by the hour.
- **Visual Timeline**: A clear vertical timeline of your scheduled events.

### 4. Specialized Women's Tools (الصحة والعناية)
- **Period Tracker**: Predict cycles, log symptoms, and get phase-specific advice.
- **Self-Care Routines**: Built-in checklists for morning and evening skincare or "Self-Love" challenges.

### 5. Mood Tracker (تتبع المزاج)
- **Daily Reflection**: Log your mood with expressive emojis.
- **Analytics**: View your mood trends over the month with visual charts.

### 6. Gamification & Engagement (التحفيز)
- **Leveling System**: Earn points and level up as you complete tasks and maintain habits.
- **Smart Assistant**: An AI-powered widget that suggests schedules and provides motivational tips based on your productivity.

### 7. Premium Customization (التخصيص)
- **3 Visual Themes**:
  - **Vibrant**: Playful pinks and rose-gold accents.
  - **Calm**: Minimalist pastels, mint greens, and lavender.
  - **Elegant**: Luxurious deep purple with gold and glassmorphic elements.
- **3D Avatar**: A customizable "Lily" character (Pixar/3D style) that represents you in the app.
- **Multi-Language**: Full support for Arabic (RTL) and English (LTR).

## 🛠 Tech Stack
- **Core**: React + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
